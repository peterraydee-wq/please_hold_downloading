# please_hold_downloading

please hold. downloading. — an incremental tragedy in bandwidth.
Here's what's in it:

Click buffer data to earn buffers manually (like stoking the fire in A Dark Room)
Spend 3 buffers to start a download — a real progress bar that fills based on your current bandwidth
Completing downloads rewards buffers and unlocks the next file tier
